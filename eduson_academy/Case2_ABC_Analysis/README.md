# Кейс 2: ABC-анализ отдела продаж

**Ссылка на Excel файл:** [Скачать Кейс2_ABC-анализ_отдела_продаж.xlsx](Кейс2_ABC-анализ_отдела_продаж.xlsx)

## Цель исследования
Комплексно оценить эффективность отдела продаж (32 менеджера, 
3 филиала): выявить ключевых сотрудников, приносящих основную 
выручку, оценить выполнение плана и систему мотивации, найти 
драйверы продаж и сформулировать рекомендации бизнесу.

## Задачи исследования
1. Подготовить данные: очистить и изменить структуру
2. Сегментировать менеджеров по вкладу в выручку (ABC-анализ)
3. Рассчитать систему мотивации (бонус, премия, активность) 
   с помощью логических функций
4. Оценить выполнение плана по менеджерам и филиалам
5. Проверить гипотезу о связи активности (звонки) и продаж
6. Визуализировать результаты и сформулировать рекомендации

## Использованные инструменты и методы
- **MS Excel** — все расчёты и визуализации
- **Логические функции** — ЕСЛИ, И, ИЛИ, НЕ, вложенные ЕСЛИ 
  (расчёт бонусов, премий, выполнения плана)
- **ABC-анализ** — сегментация менеджеров по принципу Парето (80/20)
- **Сводные таблицы** — агрегация по филиалам и выполнению плана
- **Условное форматирование** — гистограммы, цветовые шкалы, 
  выделение по условию
- **Диаграммы** — точечная (корреляция, тренды, R²), столбчатая 
  (топ-10), круговые (доли)
- **Корреляционный анализ** — линии тренда и R² для оценки 
  связи звонков и продаж
- **Очистка данных** — заполнение пустых значений, транспонирование
- **Статистические функции** — СЧЁТЕСЛИ, РАНГ, СУММ

## Ход исследования

### Этап 1: Подготовка данных (очистка и транспонирование)
В исходных данных филиал был указан только в первой строке 
группы — заполнила пустые значения во всех строках (data cleaning). 
Транспонировала таблицу для удобства анализа.

### Этап 2: ABC-сегментация (вложенные ЕСЛИ)
Отсортировала менеджеров по продажам, рассчитала долю в выручке 
и накопительный итог, присвоила категории:

`=ЕСЛИ(D3<=0,8;"A";ЕСЛИ(D3<=0,95;"B";"C"))`

- **A** — дают первые 80% выручки
- **B** — следующие 15%
- **C** — последние 5%

### Этап 3: KPI и мотивация (логические функции)
Рассчитала показатели по каждому менеджеру:

- **План выполнен:** `=ЕСЛИ(C10>=$E$3;"Да";"Нет")`
- **Бонус по грейдам (вложенные ЕСЛИ, 2–5%):** 
  `=ЕСЛИ(C10>=$A$6;C10*$B$6;ЕСЛИ(C10>=$A$5;C10*$B$5;ЕСЛИ(C10>=$A$4;C10*$B$4;ЕСЛИ(C10>=$A$3;C10*$B$3;0))))`
- **Премия (И + НЕ):** `=ЕСЛИ(И(C10>$E$3;НЕ(E10<$E$6));C10*$E$7;0)`
- **Бонус за активность (ИЛИ):** `=ЕСЛИ(ИЛИ(C10>$E$3;D10>$E$4);C10*$E$5;0)`

Применила условное форматирование: гистограммы, цветовые 
шкалы, выделение по условию.

### Этап 4: Визуализация (Дашборд)
Создала дашборд с:
- Сводными таблицами по филиалам (продажи, бонус, штат) и по 
  выполнению плана (Да/Нет, % выполнения)
- Точечной диаграммой с линиями тренда и R² по филиалам 
  (корреляция звонков и продаж)
- Топ-10 менеджеров с линией плана
- Круговыми диаграммами: доля продаж по филиалам, выполнение плана

## Выводы по результатам исследования
1. **Топ-10 менеджеров (31% штата) приносят 49% выручки** — 
   3 573 065 ₽ из 7 257 035 ₽
2. **Категория A обеспечивает 80% выручки** — классический 
   принцип Парето подтвердился
3. **Филиалы работают по-разному:** Центральный даёт 43% выручки, 
   но план выполняют лишь 19% менеджеров (тянут лидеры); 
   Троицк — самый стабильный (57% на плане)
4. **Корреляция звонков и продаж слабая (R² = 0,11–0,25)** — 
   решает качество сделок, а не количество касаний
5. **План 300 000 ₽ выполнили ровно 10 менеджеров** — они же 
   составляют весь топ-10; остальным 22 нужна поддержка или 
   пересмотр норматива
6. **Бонусный фонд — 258 087 ₽ (3,6% от выручки)** — разумная 
   нагрузка на ФОТ

**Рекомендации бизнесу:**
- Центральный филиал: разобрать практики топ-менеджеров с 
  остальными (менторство)
- Троицк: масштабировать подход на другие филиалы
- Пересмотреть норматив звонков, сместить фокус на встречи и 
  качество сделок
