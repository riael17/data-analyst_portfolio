# SQL-запросы для анализа продаж Northwind

**Ссылка на скрипт с кодом:** [queries.sql](queries.sql)

## Цель исследования
Проанализировать данные компании Northwind с помощью базовых SQL-запросов (SELECT, WHERE, ORDER BY, LIKE, CASE) для извлечения, фильтрации и сортировки информации о товарах, клиентах и заказах.

## Задачи проекта
- Изучить структуру таблиц базы данных
- Выполнить выборку данных с различными условиями фильтрации
- Применить текстовый поиск и работу с шаблонами
- Категоризировать товары по цене
- Выявить пропущенные значения в данных

## Описание проекта
Проект выполнен в рамках обучения SQL. Использовалась учебная база данных Northwind, развернутая на PostgreSQL. В ходе работы написаны SQL-запросы для решения практических бизнес-задач: анализ ассортимента, географии клиентов, складских запасов.

## Инструменты
- SQL (PostgreSQL)
- DBeaver

## Структура базы данных
**Основные таблицы:**
- `products` — товары (название, цена, количество на складе)
- `customers` — клиенты (название компании, город, страна, контакты)
- `orders` — заказы (дата заказа, дата доставки, клиент)
- `order_details` — детали заказов (товар, количество, цена)
- `employees` — сотрудники
- `suppliers` — поставщики
