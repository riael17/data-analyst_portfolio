# Визуальный анализ данных о медицинском страховании

- **Ссылка на код:** [medical_insurance_analysis.ipynb](./medical_insurance_analysis.ipynb)
- **Компания:** HealthGuard Insurance
- **Источник данных:** [Kaggle: Medical Cost Personal Datasets](https://www.kaggle.com/datasets/mirichoi0218/insurance)

## 1. Цель проекта
Изучить данные клиентов медицинской страховой компании и наглядно визуализировать ключевые факторы, влияющие на размер страхового взноса (`charges`), для подготовки аналитической записки и рекомендаций для руководства.

## 2. Описание проекта
Проект выполнен в рамках обучения визуализации данных на Python. Использовался открытый датасет, содержащий информацию о клиентах: возраст, пол, индекс массы тела (BMI), количество детей, статус курения, регион проживания и итоговая стоимость полиса. 
Основной фокус работы был сделан на визуальном поиске зависимостей и оценке рисков с помощью продвинутых возможностей библиотек Seaborn и Matplotlib (`pairplot`, `lmplot`, кастомизация `scatterplot`).

## 3. Ключевые выводы по бизнес-задачам
В рамках проекта решены 4 ключевые задачи визуального анализа:
- **Задача 1 (Оценка общего профиля):** Выявлено, что статус курения (`smoker`) является самым сильным визуальным разделителем в данных, формируя две отчетливые группы: стоимость полиса для курящих в среднем в 3–4 раза выше.
- **Задача 2 (Анализ факторов риска):** Построена матрица парных графиков (`pairplot`), которая показала, что возраст и индекс массы тела (BMI) имеют слабую линейную корреляцию со стоимостью у некурящих, но резкую нелинейную зависимость у курящих клиентов.
- **Задача 3 (Детализация и тренды):** С помощью диаграмм рассеяния с линиями линейной регрессии (`lmplot`) подтверждено, что рост BMI у курящих клиентов ведет к непропорционально высокому увеличению страхового взноса. Доверительные интервалы подтвердили статистическую значимость этого тренда.
- **Задача 4 (Сегментация):** Разбивка данных по полу (`sex`) и региону (`region`) с помощью фасетных сеток показала, что выявленные закономерности носят устойчивый характер и не зависят от конкретной демографической группы.

## 4. Итоговые рекомендации для бизнеса
- **Скоринг рисков:** Внедрить повышающие коэффициенты или обязательное медицинское обследование для клиентов с комбинацией факторов "курение + BMI > 30", так как именно эта группа формирует основные финансовые риски компании.
- **Программы лояльности (Wellness):** Разработать специальные условия или скидки на полисы для клиентов, подтверждающих отказ от курения или снижение BMI в течение года (программы удержания и профилактики).

## 5. Технические особенности реализации
- Проект выполнен в среде **Jupyter Notebook** (интеграция через VS Code).
- Для гарантии **воспроизводимости кода** (reproducibility) и изоляции от системных конфликтов использовалось изолированное виртуальное окружение (Conda/venv). Это позволило избежать проблем с рендерингом шрифтов Matplotlib на macOS и обеспечить стабильную работу на любой машине.
- Применена продвинутая кастомизация графиков: 
  - Одновременное кодирование категориальных переменных цветом (`hue`) и формой маркеров (`style`).
  - Построение линий регрессии с 95% доверительными интервалами для оценки надежности трендов.
  - Настройка глобального стиля визуализации через `sns.set_theme(style="whitegrid")` для создания единого корпоративного стиля отчетов.
